# Experiment 07 – Working with jQuery

## Description
This experiment demonstrates the use of jQuery to develop interactive web applications for a TechZone Electronics Store. It includes a Budget Calculator, Electronics Order Calculator, and Product Customization Workshop. jQuery methods are used to handle click events, retrieve input values, display results, perform calculations, and dynamically modify webpage styles.

## Objectives
- To create interactive web applications using jQuery.
- To perform budget calculations based on percentages.
- To calculate the total price of selected electronic products.
- To modify product appearance using jQuery CSS methods.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- jQuery

## jQuery Methods Used
- `$(document).ready()`
- `click()`
- `val()`
- `html()`
- `css()`

1. TechZone Budget Calculator
2. Electronics Order Calculator
3. Product Customization Workshop
